Chép ảnh món ăn vào thư mục này, đặt tên file đúng như danh sách bên dưới (đuôi .jpg, .png hoặc .webp đều được).
Xong thì tắt API (Ctrl + C) và chạy lại dotnet run, API tự gắn ảnh cho món chưa có ảnh.
Món thêm sau: tên file = tên món bỏ dấu, nối bằng gạch ngang.
