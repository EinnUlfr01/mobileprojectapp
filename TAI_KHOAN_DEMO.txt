3. CÁC BƯỚC CHẠY TRƯỚC KHI DEMO
-------------------------------------------------
Bước 1 - Chạy API (mở terminal riêng, để nguyên cửa sổ này suốt buổi demo):
    cd D:\Projects\DoAnAppGiaodoan\backend\FoodOrder.API
    dotnet run

Bước 2 - Nối 2 máy vào API (gõ trong Terminal của Android Studio):
    D:\Android\SDK\platform-tools\adb.exe -d reverse tcp:5090 tcp:5090
    D:\Android\SDK\platform-tools\adb.exe -e reverse tcp:5090 tcp:5090
    (-d = điện thoại cắm cáp USB, -e = máy ảo)

Bước 3 - Chọn từng máy ở ô thiết bị trên thanh công cụ Android Studio rồi bấm Run.

Lưu ý: app báo "Không kết nối được server" thì chạy lại 2 lệnh ở Bước 2
(khi rút cáp cắm lại, tắt mở máy ảo hoặc mở lại Android Studio).
